PumpkinWave 666

Haunted firmware for the M-VAVE FM-1: 103 horror and sci-fi DX7 voices, 25 user slots, the HAUNT LAB sound designer and a jack-o'-lantern UI. Built on M-VAVE's FM1 Open V14.

Flash your FM-1

  1. Use desktop Chrome or Edge. The flasher talks to the FM-1 over Web MIDI, so phones and Safari or Firefox won't work.
  2. Connect the FM-1 by USB-C and switch it on. A charged battery is safest.
  3. Open the flasher, go to Projects & sounds and back up your projects, DX7 voices and samples. Switching firmware does not convert their formats.
  4. Go to Device update and select Connect device, then allow MIDI and SysEx when the browser asks.
  5. Start the update. Keep the cable connected and the page open until it reports success.
  6. When it restarts, the green-eyed pumpkin should greet you. Press SEL on a DX7 track to open HAUNT LAB.

Unofficial firmware: read before flashing

  • PumpkinWave 666 is not made or supported by M-VAVE. You flash it at your own risk.
  • The flasher page also contains M-VAVE's original V15 firmware, so you can return to stock from the same Device update page. M-VAVE's download page has it too.
  • Each build is compiled by this repository's GitHub Actions from the public source. The SHA-256 is shown above and in SHA256SUMS.txt.
