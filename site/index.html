PumpkinWave 666

Haunted firmware for the M-VAVE FM-1: 103 horror and sci-fi DX7 voices, 25 user slots, the HAUNT LAB sound designer and a jack-o'-lantern UI. Built on M-VAVE's FM1 Open V14.

Flash your FM-1

  1. Use desktop Chrome or Edge. The flasher talks to the FM-1 over Web MIDI, so phones, Safari and Firefox won't work.
  2. Close every other program that might be using the FM-1's MIDI port: M-VAVE's own update tool, DAWs, Dexed, and other workbench or flasher tabs. On Windows only one program can hold the port.
  3. Connect the FM-1 by USB-C with a data cable and switch it on.
  4. Open the flasher and go to the Device update tab. Ignore the "Connect device" button in the top corner for now: it only talks to FM1 Open-family firmware, so a unit running M-VAVE's stock firmware won't show up there.
  5. Select Connect device in the Device update tab and allow MIDI and SysEx when Chrome asks.
  6. If the FM-1 runs stock firmware (V15 or V16) or another custom firmware, the page says it found other firmware. Select Enable force flashing and reconnect. That only switches the mode; nothing is written yet.
  7. Tick the backup confirmation, then select Force update (or Update) and confirm. Keep the cable connected and the page open until it reports success. Switching firmware can clear projects and samples. If you're already on FM1 Open, back them up first in Projects & sounds.
  8. When the unit restarts, the green-eyed pumpkin should greet you. Press SEL on a DX7 track to open HAUNT LAB.

If the FM-1 isn't found

  • "Browser did not find MIDI input and output": Chrome can't see the FM-1. Try another cable or USB port, switch the unit off and on, then reload the page. Check that the site is allowed to use MIDI (padlock icon, then Site settings, then MIDI devices).
  • "Found MIDI ports, but the device did not reply": another program is holding the port. Close it, unplug and replug the FM-1, and connect again.
  • "Other firmware recognized": this is expected from stock firmware. Use Enable force flashing and reconnect (step 6).
  • Open Connection details under the Device update panel to see exactly which MIDI ports Chrome found.
  • On Linux, Chrome may need chrome://flags to allow Web MIDI, or your user may need to be in the audio group.

Unofficial firmware: read before flashing

  • PumpkinWave 666 is not made or supported by M-VAVE. You flash it at your own risk.
  • The flasher page also contains M-VAVE's original V15 firmware, so you can return to stock from the same Device update page. M-VAVE's download page has it too.
  • Each build is compiled by this repository's GitHub Actions from the public source. The SHA-256 is shown above and in SHA256SUMS.txt.
